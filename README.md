# Контрольная работа по FastAPI

## Описание проекта
Проект содержит реализацию заданий 3.1, 3.2, 5.1-5.5 по курсу FastAPI.

В проекте реализованы:

- создание пользователя с использованием **Pydantic**
- работа с **API для продуктов**
- **аутентификация пользователей**
- защита маршрутов через **dependencies**
- работа с **HTTP заголовками**

Проект структурирован по модулям, чтобы код был легко читаемым и расширяемым.

----
## Структура проекта

```

fastapi-control-work/
│
├── app/
│   ├── task_3_1/        # Задание 3.1 - Создание пользователя
│   ├── task_3_2/        # Задание 3.2 - Работа с продуктами
│   ├── task_5_1_2_3/    # Задания 5.1–5.3 - Аутентификация
│   └── task_5_4_5/      # Задания 5.4–5.5 - Заголовки
│
├── examples/            # Примеры HTTP запросов
├── docs/                # Документация и скриншоты
│
├── main.py              # Главный файл приложения
└── requirements.txt     # Зависимости проекта

````

# Установка и запуск

## 1. Клонировать репозиторий

```bash
git clone <url репозитория>
cd fastapi-control-work
````

---

# 2. Создать виртуальное окружение

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

---

# 3. Установить зависимости

```bash
pip install -r requirements.txt
```

---

# 4. Запустить приложение

```bash
uvicorn main:app --reload
```

Сервер запустится по адресу:

```
http://localhost:8000
```

---
